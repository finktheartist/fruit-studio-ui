Fruit Studio UI

Four ordinary controls built from macro-photographed fruit resting on matte alabaster porcelain. Cleave them with real swipe physics, splash Beer-Lambert viscous nectar across the ceramic, or swipe upward to juggle pieces for combos. Each one is a single file with no dependencies.

The repo on GitHub ↗ @crtvTeknologist on X ↗

Swipe downward or sideways to drop cleaved halves off-screen. Easter egg: swipe upward through any fruit to launch only that fruit into hang-time, then keep your finger down across multiple floating pieces for Double, Triple, Quad, Penta and Hexa combos. Sound plays after your first gesture; FruitStudio.Sound.on = false turns it off.
